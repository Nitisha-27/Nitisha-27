### 🫀 [ECG-Based Sleep Apnea Detection](https://github.com/Nitisha-27/ECG-Based-Sleep-Apnea-Detection-using-Machine-Learning)


Machine learning pipeline for distinguishing apnea and non-apnea subjects using ECG-derived features.

- Processed data from 63 subjects: 35 apnea and 28 healthy.
- Engineered 13 temporal and HRV features.
- Tuned an XGBoost classifier and explored knowledge distillation into a Decision Tree.
- Reported ROC-AUC: **0.9773 (XGBoost)** and **0.9091 (Decision Tree)** in the evaluated models.

**Stack:** Python · NeuroKit2 · Pandas · Scikit-learn · XGBoost · Optuna

*Research prototype; not clinically validated.*
